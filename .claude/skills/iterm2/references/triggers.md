# Triggers

セッションの出力（画面に流れてくるテキスト）を正規表現でマッチさせ、色付け・通知・自動入力・スクリプト呼び出しなどを起動する仕組み。設定場所は **Settings > Profiles > Advanced > Triggers**。

## 正規表現の仕様

- ICU正規表現（Unicode標準準拠）。PCREとほぼ互換だが細部の挙動が違うことがあるので複雑なパターンは実機で確認する。
- 1回のマッチ判定は基本的に1行単位。デフォルトでは改行かカーソル移動のエスケープシーケンスが来たタイミングで評価される。
- パフォーマンス対策として、長い行は末尾の数行分しか対象にならない制限がある（詳細設定で緩められる）。
- `Instant` オプションを有効にすると、行末を待たずに文字が流れてきた時点でマッチ次第すぐ発火する。パスワードプロンプトなど「改行が来ない」出力に反応させたいときに必須。

## 使えるアクション（代表的なもの）

| カテゴリ | アクション | 用途 |
|---|---|---|
| 表示 | Highlight Text / Highlight Line | マッチ箇所・行に背景色/文字色を付ける |
| 表示 | Annotate | マッチ箇所にメモを紐付ける（バルーン表示） |
| 通知 | Post Notification | macOSの通知センターに通知を出す |
| 通知 | Show Alert | モーダルアラートを出す |
| 入出力 | Send Text | 固定文字列またはプレースホルダを含む文字列をそのセッションに送り込む（自動応答に使う） |
| 入出力 | Inject Data | バイト列を入力ストリームに直接挿入 |
| 入出力 | Capture Output | マッチした出力をキャプチャバッファに保存（後でCapture Output Toolbeltから参照） |
| 入出力 | Make Hyperlink | マッチ箇所をクリック可能なハイパーリンクにする |
| 実行 | Run Command | マッチをトリガーに外部コマンドを実行（画面には影響しない） |
| 実行 | Invoke Script Function | Python APIに登録した関数を呼び出す（[python-api.md](python-api.md)参照） |
| 実行 | Run Coprocess / Run Silent Coprocess | マッチをトリガーにコプロセス（セッションの入出力を横取りできる外部プロセス）を起動 |
| ナビゲーション | Set Mark / Set Named Mark | ジャンプ用のマークを打つ（Cmd+Shift+↑/↓や検索で使える） |
| ナビゲーション | Fold to Named Mark | マーク間を折りたたむ |
| その他 | Set Title / Set Profile | セッションのタイトルやプロファイルを動的に切り替える |

## プレースホルダ（Send Text / Run Command などで使用可）

| 記法 | 意味 |
|---|---|
| `\0` | マッチ全体 |
| `\1`〜`\9` | キャプチャグループ |
| `\e` | ESC (0x1B) |
| `\n` / `\t` | 改行 / タブ |
| `\xNN` | 任意の16進バイト |

## 実用例

**ビルド失敗を通知する**
- 正規表現: `BUILD FAILED|FAIL\b`
- アクション: Post Notification
- テキスト: `ビルド失敗: \0`

**"Are you sure? [y/N]" に自動でNoを返す（Instant必須）**
- 正規表現: `Are you sure.*\[y/N\]`
- アクション: Send Text、Instant: ON
- テキスト: `n\n`
- ※ 意図しないコマンドに自動応答してしまうリスクがあるため、正規表現は対象を絞り込む。特にリモートホストの出力に対して設定する場合は、信頼できないホストの出力で誤発火しないか確認する。

**IPアドレスをハイライト**
- 正規表現: `\b(?:\d{1,3}\.){3}\d{1,3}\b`
- アクション: Highlight Text

**エラー行にマークを打って後で `Cmd+Shift+↑/↓` で辿れるようにする**
- 正規表現: `^ERROR`
- アクション: Set Mark

## セキュリティ上の注意

Trigger は**セッションに流れてくる任意の文字列**をトリガーにできるため、`Run Command` や `Send Text`、`Invoke Script Function` を使う設定は「信頼できない出力（他人が制御できるSSH先、ログファイルのtailなど）」によって意図しない動作を誘発される可能性がある（プロンプトインジェクションに近い構造）。正規表現をできるだけ厳密にし、任意コマンド実行に繋がるアクションは信頼できる自分のマシン上の出力にのみ使う。
